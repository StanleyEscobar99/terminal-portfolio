# Cybersecurity Terminal Portfolio

Interactive terminal-style portfolio built to showcase my cybersecurity background, technical skills, certifications, and completed projects.

## Features

- Terminal-style command interface
- Cybersecurity-focused About section
- Completed project showcase
- Professional certifications
- Contact information
- Command autocomplete
- Interactive terminal commands and easter eggs

## Commands

- `whoami`
- `about`
- `projects`
- `certs`
- `contact`
- `ls`
- `help`
- `clear`

Terminal-style navigation also works with commands such as:

- `cd about`
- `cd projects`
- `cd certs`
- `cd contact`
